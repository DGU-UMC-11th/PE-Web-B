# UMCine 7주차 (프론트엔드)

6주차 프론트엔드 코드에 7주차 워크북 본문 실습과 필수 미션을 반영했습니다.

## 실행

1. `.env.example`을 복사해 `.env.local`로 만들고 **본인 TMDB Read Access Token**을 설정하세요.
2. 회원가입과 중복 확인을 실제로 확인하려면 기존 5~6주차 Spring Boot 서버를 `http://localhost:8080`에서 실행하세요. (서버 코드는 제공한 ZIP에 없으므로 포함하지 않았습니다.)
3. 터미널에서 다음 명령을 실행하세요.

```sh
pnpm install
pnpm dev
```

## 경로

- `/`: 기존 영화 목록
- `/search`: 기존 영화 검색
- `/movies/:movieId`: 기존 영화 상세
- `/signup`: 7주차 회원가입 폼 (입력 유효성, 이메일/닉네임 중복 확인, `POST /members`)
- `/login`: 필수 미션 로그인 화면 퍼블리싱 (인증 요청 없음)
- `/mypage`: 필수 미션 내 정보 조회 화면 퍼블리싱 (디자인의 예시 정보 표시)
- `/mypage-edit`: 필수 미션 내 정보 수정 화면 퍼블리싱 (닉네임 입력 및 브라우저 내 값 반영)

**범위:** 7주차는 로그인/내 정보 API 연동을 하지 않습니다. 내 정보의 이메일, 즐겨찾기는 디자인 PDF의 예시 데이터이며 서버 데이터가 아닙니다. 내 정보 수정의 이미지 선택은 미리보기만 제공하며 서버에 업로드되지 않습니다. 이 화면에서 회원 탈퇴 기능은 동작하지 않습니다. 선택 미션은 포함하지 않았습니다.

## 유의

- `VITE_TMDB_ACCESS_TOKEN`은 사용자별 발급 정보이므로 포함하지 않았습니다.
- 회원가입 요청은 워크북에서 정의한 `GET /members/email/{email}`, `GET /members/nickname/{nickname}`, `POST /members`를 그대로 사용합니다.
- 기존 프로젝트에는 `@/` 별칭 설정이 없어 워크북의 import 문을 기존 코드와 동일한 상대 경로 import로 작성했습니다.
