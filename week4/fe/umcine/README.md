# UMCine — 공개 영화 화면

React + TypeScript + TanStack Router + Tailwind CSS v4로 구현한 로컬 영화 서비스입니다.

## 실행

```sh
pnpm install
pnpm dev
pnpm lint
pnpm build
pnpm preview
```

## 라우팅과 데이터

- `/`: 로컬 영화 목록 10편. 포스터 또는 제목을 누르면 상세 화면으로 이동합니다.
- `/search`: 검색어 입력 안내.
- `/search?query=스파이더맨`: 한글 제목 또는 원제를 부분 검색합니다. 앞뒤 공백과 영문 대소문자를 무시하며, 제공된 데이터에서는 2편이 나옵니다.
- `/movies/1`: 배경, 포스터, 제목, 원제, 개봉일, 장르, 상영시간, 태그라인과 줄거리를 표시합니다.
- `/movies/999`: `영화를 찾을 수 없어요.` 안내.

원본 데이터는 `src/data/movies.ts`입니다. PDF의 예시 검색 결과 수·페이지 수를 하드코딩하지 않습니다. 목록은 페이지당 10편으로 계산해 현재 1페이지를 표시합니다.

## 화면 기준과 범위

제공된 `영화 페이지.pdf`의 목록·검색·상세 데스크톱 화면을 기준으로 구현했습니다. 이미지와 줄거리 내용은 제공된 로컬 데이터를 사용하므로 PDF 예시와 다를 수 있습니다. 작은 화면에서는 검색 결과와 상세 영역이 한 열로 배치됩니다.

기존 `App.css`와 사용하지 않는 `App.tsx`를 제거했습니다. 전역 Tailwind 설정은 `src/index.css`에 있으며, 상태에 따라 달라지는 클래스는 `cn`을 사용합니다.

로그인·내 정보는 필수 미션 범위에 포함되지 않아 연결하지 않았습니다. 즐겨찾기는 루트의 MoviesProvider에서 관리하며 목록과 상세 화면이 같은 영화 ID의 상태를 공유합니다. 화면 이동 시 유지되지만 새로고침하면 로컬 데이터의 초기값으로 돌아갑니다. 평점·후기는 해당 브라우저의 로컬 저장소에 저장됩니다.

## 검증

- `pnpm lint`, `pnpm build` 통과.
- 목록·검색·상세 직접 URL 접근 및 새로고침 확인.
- 카드 및 검색 결과 → 해당 상세 화면 이동 확인.
- 검색어 없음, 결과 없음, 영문 대소문자, 공백, 뒤로가기 확인.
- 잘못된 영화 ID 안내 확인.
- 1440×1024 데스크톱과 390×844 모바일 확인.
- 브라우저 Console 오류·경고 없음 확인.

정적 호스팅에 배포할 때는 `/search`, `/movies/*` 요청을 `index.html`로 보내는 SPA fallback 설정이 필요합니다. Vite 개발 서버와 preview에서는 기본 제공됩니다.
